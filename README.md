# Task 2: Personal Portfolio Website

**Internship Track:** Web Development & Designing (OIBSIP)  
**Deliverable Folder:** `OIBSIP/WebDev-L1-Portfolio/`  
**Tech Stack:** HTML5, CSS3  

---

## 📌 Project Overview
A fully responsive personal developer portfolio website highlighting professional identity, core skillsets, featured project deliverables, and contact information. Built with semantic HTML5 and clean modern CSS layout techniques.

## 🚀 Implemented Features
- [x] **Hero/Profile Section:** Name, professional title, taglines, and circular avatar placeholder.
- [x] **About Me Section:** Background summary, developer focus, and career goals.
- [x] **Skills Grid:** Interactive flex/grid tech chips displaying core frontend competencies.
- [x] **Projects Showcase:** Clean cards showcasing Level 1 tasks with descriptions, tech pills, and direct repository links.
- [x] **Contact Section:** Direct email link and social navigation (GitHub, LinkedIn).
- [x] **Smooth Scrolling:** Clean in-page anchor scrolling between sections.
- [x] **Responsive Layout:** Optimized with CSS Flexbox & CSS Grid for mobile, tablet, and desktop viewports.
